# Setting Up Your AutoResearch Application

## Getting Started with Gemini API

1. First, get your Gemini API key:
   - Go to https://makersuite.google.com/app/apikey
   - Create a new API key if you haven't already
   - Copy your API key

2. Configure the Application:
   - Go to http://localhost:8501 in your browser
   - Click on "Configuration Check" in the sidebar
   - Paste your Gemini API key in the "Gemini API Key" field
   - Click "Test Configuration" to verify and save the key

3. Using the Application:
   - Return to the main page
   - Enter a research topic
   - Click "Start Research" to begin

## Demo Mode
If you haven't configured your API key, the application will run in demo mode with example data.

## Need Help?
If you encounter any issues:
1. Make sure your Gemini API key is correct
2. Check that you have a stable internet connection
3. Try refreshing the page after adding the API key
